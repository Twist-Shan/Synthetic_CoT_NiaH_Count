\begin{abstract}
Counting repeated records in a long context is a minimal task that nevertheless requires retrieval, aggregation, and a stable discrete readout. We study language models under direct-answer and trace-generating conditions; causal mode comparisons are restricted to identical weights. A behavioral audit currently covers 26,500 realistic needle-in-a-haystack requests across context length, target count, prompting mode, and model family. Explicit enumeration and native reasoning often improve counting, but strict-format accuracy can substantially understate numerical accuracy. We therefore formulate a mechanistic account that is deliberately stronger than probe accuracy: direct answering is hypothesized to use distributed target tagging, broad parallel retrieval, and a compressed global count readout, whereas trace generation is hypothesized to use targeted retrieval together with separable progress/termination and final-total states. We define the states, identifiability controls, conditional dispersion measures, and causal interventions needed to distinguish these accounts, and use trained-from-scratch synthetic transformers as a controlled bridge. Preliminary synthetic results support distinct routing strategies and causally executable count states in a one-seed toy setting; realistic-LLM causal validation remains incomplete. \inlineTODO{Replace this final sentence with preregistered Qwen/Gemma causal results and confidence intervals.}
\end{abstract}

\section{Introduction}

Long-context benchmarks often ask whether a model can retrieve one item from a large distractor context. Counting extends retrieval in a small but consequential way: the model must identify \emph{all} matching records, avoid duplicates, aggregate them, and map an internal magnitude to an exact integer. This is close to the multi-needle aggregation regime emphasized by RULER~\citep{hsieh2024ruler}, and it exposes failure modes that a single-needle test cannot.

Chain-of-thought (CoT) can improve reasoning accuracy~\citep{wei2022cot}, but an emitted trace is not automatically a faithful description of the internal computation~\citep{turpin2023unfaithful}. The central question of this paper is therefore mechanistic rather than purely behavioral:

\begin{quote}
\emph{Does direct answering count by a parallel, approximate aggregation over many retrieved records, while thinking converts the same problem into targeted retrieval and serial aggregation?}
\end{quote}

Earlier exploratory evidence is compatible with a more precise version of this contrast. In direct mode, target recall can remain high when the total is wrong, suggesting---but not establishing---an aggregation/readout bottleneck. In trace-generating mode, the model may externalize intermediate items, but the state that controls trace progress need not be the state that controls the final total. Consequently, we distinguish a \emph{count code} from an \emph{algorithmic counter}, and we separate target validity, source identity, progress, termination, final aggregation, and output conversion.

This working paper makes four contributions, with their present status stated explicitly:

\begin{enumerate}
  \item We give falsifiable definitions of target-validity tags, source ordinals and pointers, prefix counters, aggregation states, semantic progress, broad retrieval, targeted retrieval, successor control, and conditional representation dispersion.
  \item We consolidate a realistic benchmark over $N\in\{1,2,3,4,5,6,8,10,20,30\}$ needles and $L\in\{2,3,5,10,20\}$k tokens, separating numerical accuracy from parsing, formatting, and truncation.
  \item We specify a causal evidence ladder---steering, residual and head-output patching, query-local ablation, and mediation---for Qwen3 and Gemma4 models that expose thinking and non-thinking modes~\citep{yang2025qwen3,gemmateam2026gemma4}.
  \item We use synthetic transformers to study when routing roles and count-state geometry emerge during training. Existing results motivate the LLM experiments but do not substitute for them.
\end{enumerate}

\section{Problem Setup and Mechanistic Definitions}
\label{sec:definitions}

\subsection{Task and modes}

Let a tokenized context be $x_{1:T}$. It contains candidate record spans $R_1,\ldots,R_M$, closed at positions $t_1<\cdots<t_M$. The task predicate assigns validity $y_i\in\{0,1\}$ to candidate $R_i$; the target spans $S_1,\ldots,S_N$ are the subsequence with $y_i=1$. Let $z_t=\sum_i y_i\mathbf 1[t=t_i]$. The gold total and token-prefix total are
\begin{equation}
  \gold=\sum_{t=1}^{T}z_t=N,
  \qquad
  C_{\le t}=\sum_{u\le t}z_u.
\end{equation}
The model is evaluated in four prompting modes: (i) \textsc{Direct}, a strict total-only answer; (ii) \textsc{Index}, a numbered enumeration followed by a total; (iii) \textsc{Bullet}, an unnumbered bullet enumeration followed by a total; and (iv) \textsc{Native Thinking}, in which the checkpoint's native reasoning mode is enabled before the final total. We estimate three effects separately: explicit trace elicitation (Index/Bullet versus Direct), a same-checkpoint native-mode toggle, and additional generated-token/compute budget. ``Thinking'' is only an umbrella description and never a pooled causal estimand.

For layer $\ell$ and semantic anchor $a$, $\hidden_a^\ell\in\R^d$ denotes the post-block residual stream before the token to be predicted. Anchors, not raw token offsets, define the analysis. This matters because trace length, tokenization, and answer position can all covary with count.

\subsection{Count code versus counter}

\begin{definition}[Count code]
A site $(a,\ell)$ carries a count code for label $c$ if a decoder fitted on training documents predicts $c$ above lexical, position-only, and shuffled-label controls on held-out document templates, counts, lengths, target identities, and depths. A count code is a property of a representation; it need not be used by the model.
\end{definition}

\begin{definition}[Target-validity tag]
A candidate-end state carries a target-validity tag if it predicts $y_i$ under identity, template, token, and position holdouts, and a local intervention changes whether $R_i$ contributes to a downstream aggregate while matched candidate states do not. Testing only gold target endpoints cannot establish a validity tag.
\end{definition}

\begin{definition}[Source ordinal and pointer]
The source ordinal of candidate $R_i$ is its candidate index $i$ (or registered depth), independent of $y_i$. A pointer state identifies which source span $R_i$ is being routed at a trace step. This differs from the \emph{target rank} $r_i=\sum_{j\le i}y_j$: at a valid target endpoint, $r_i=C_{\le t_i}$ by construction.
\end{definition}

\begin{definition}[Carried prefix counter]
A sequence of prompt-local states carries a prefix counter if states after target and matched non-target boundaries encode $C_{\le t}$, the state persists through intervening filler, target events induce an approximately unit update while matched distractors do not, and patching that state changes the final count in the predicted direction.
\end{definition}

\begin{definition}[Aggregation state]
A state is an aggregation state if adding, deleting, duplicating, or flipping the validity of one source record changes it in the registered direction and restoring the state mediates that record's effect on the final total. A direct terminal aggregate is formed at a late summary/answer site; a serial trace aggregate is updated across aligned trace items. Decoding the total without these set-level counterfactuals is insufficient.
\end{definition}

\begin{definition}[Trace progress register]
For a free-running trace, let $k_{\rm emit}$ be the emitted-item count, $k_{\rm valid}$ the number of source-aligned valid items, $k_{\rm unique}$ the number of unique valid sources covered, and $N-k_{\rm unique}$ the remaining total. A progress register is a pre-index or item-end state that encodes a preregistered semantic label---primary: $k_{\rm unique}$---and causally controls retrieval of another item or termination after emitted step, item validity, and duplication are varied independently. Decoding $k_{\rm emit}$ from a visible index or its position is insufficient.
\end{definition}

\begin{definition}[Algorithmic counter]
A family of states is an algorithmic counter only if it is readable, causally transportable, and follows a stable update law $s_{k+1}\approx F(s_k,e_k)$ that generalizes to held-out counts, positions, and event identities. A linearly decodable scalar at the answer query is insufficient.
\end{definition}

This distinction resolves where to search for a non-thinking counter. The primary site for a \emph{total-count code} is the answer query, compared across matched prompts with different totals. Prompt-local candidate and filler sites address a separate question: whether the model maintains a carried prefix counter during the same forward pass. Natural target endpoints alone cannot identify that question because target rank and prefix count are identical there. The primary design therefore fixes candidate ordinal while flipping validity, fixes the number of seen candidates while varying the valid prefix, and tests persistence at matched filler boundaries. A sweep over separately truncated prompts is useful corroboration, but it cannot alone prove a persistent within-sequence state.

\subsection{Retrieval and routing roles}

Let $A^{\ell h}_{qj}$ be the attention probability from query $q$ to key $j$ for head $h$ in layer $\ell$. For target span $S_i$, define span mass $a_i^{\ell h}(q)=\sum_{j\in S_i}A^{\ell h}_{qj}$ and total target mass
\begin{equation}
 M_N^{\ell h}(q)=\sum_{i=1}^{N}a_i^{\ell h}(q),
 \qquad r_i^{\ell h}(q)=a_i^{\ell h}(q)/(M_N^{\ell h}(q)+\epsilon).
\end{equation}
For $N\ge2$, normalized target coverage and the broad-retrieval score are
\begin{equation}
 H_N=-\frac{\sum_{i=1}^{N}r_i\log(r_i+\epsilon)}{\log N},
 \qquad B_{\ell h}=M_NH_N.
 \label{eq:broad}
\end{equation}
We report $M_N$ and $H_N$ separately and treat $N=1$ as an edge case rather than assigning evidential weight to an arbitrary entropy convention.

For the $k$th trace retrieval query $q_k$ aligned to source span $S_{\pi(k)}$, targeted selectivity is
\begin{equation}
 T_{\ell h}=\E_{x,k}\left[
 \frac{a_{\pi(k)}^{\ell h}(q_k)}{\sum_{i=1}^{N}a_i^{\ell h}(q_k)+\epsilon}
 \right],
 \label{eq:targeted}
\end{equation}
reported together with raw matched mass, matched-target top-1 accuracy, and an example-balanced aggregation over $k$. These are head-level discovery scores. A system-level broad-retrieval claim additionally requires union coverage across the selected head/path bundle, value/output contribution, and predictable leave-one-target-out/add-one-target effects. A set of individually narrow heads can therefore implement a broad system, and absence of direct answer-query attention does not rule out a multi-hop summary path. A \emph{successor/termination} candidate acts at the item-end anchor and changes the next-index-versus-close decision. A \emph{trace-readout} candidate acts at the final answer query and routes information from trace anchors. These score-based labels become functional classes only after held-out causal tests; one head may have more than one role.

\subsection{Noise and count-state geometry}

Let the observed counts be $c_1<\cdots<c_J$, and let $\mu_j^\ell=\E[\hidden_a^\ell\mid C=c_j]$ and $\Sigma_j^\ell=\Cov(\hidden_a^\ell\mid C=c_j)$ after residualizing registered nuisances. Hidden states are deterministic given an exact input; ``noise'' below means conditional representation dispersion across matched prompts. For adjacent observed counts define $\Delta c_j=c_{j+1}-c_j$, unit tangent $t_j=(\mu_{j+1}-\mu_j)/\|\mu_{j+1}-\mu_j\|_2$, per-count spacing $d_j=\|\mu_{j+1}-\mu_j\|_2/\Delta c_j$, and pooled covariance $\bar\Sigma_j=(\Sigma_j+\Sigma_{j+1})/2$. We report
\begin{align}
 \text{tangential dispersion}(j)&=
   \frac{t_j^\top\bar\Sigma_jt_j}{d_j^2+\epsilon},\\
 \text{normal RMS}(j)&=
   \sqrt{\frac{\operatorname{tr}(P_{t_j}^{\perp}\bar\Sigma_j)}{d-1}},\\
 \text{local SNR}(j)&=
   \frac{d_j^2}{t_j^\top\bar\Sigma_jt_j+\epsilon},\\
 D^2_{M,j}&=\frac{(\mu_{j+1}-\mu_j)^\top
 (\bar\Sigma_j+\lambda I)^{-1}(\mu_{j+1}-\mu_j)}{(\Delta c_j)^2}.
 \label{eq:noise}
\end{align}
We additionally report conditional decoder bias, variance, and mean squared error. Dense $C=1{:}30$ samples are the primary heteroscedasticity set; otherwise every adjacent metric is gap-normalized as above. These within-label quantities must accompany centroid plots: PCA of class means alone says nothing about dispersion.

\section{Mechanistic Hypotheses}

\begin{hypothesis}[Direct broad aggregation]
Direct mode identifies target records in distributed prompt representations, routes many of them through a broad head/path bundle, forms a compressed global magnitude in later layers, and maps that magnitude through a quantized numeric-token readout. It need not maintain a persistent prefix counter at source positions.
\end{hypothesis}

\begin{hypothesis}[Trace-targeted retrieval and serial control]
A trace-generating condition repeatedly targets a particular source record, updates a progress/termination register, and later constructs a distinct final-total state. The visible trace supplies extra serial computation and an external memory, but the last written index is not necessarily the final count source.
\end{hypothesis}

\begin{hypothesis}[Heteroscedasticity]
As $C$ grows, direct-mode per-count spacing contracts and/or conditional dispersion grows, causing local SNR to decrease faster than in trace-generating modes. The primary comparison is final-total versus final-total on a preregistered dense count set and prespecified overlapping-difficulty cells; correctness-conditioned and post-hoc iso-accuracy analyses are sensitivity checks. Trace progress $k$ is never compared directly with a direct total $C$.
\end{hypothesis}

An abrupt hidden-state norm change at a target is neither necessary nor sufficient for Hypothesis 1. We will nevertheless test a candidate-level difference-in-differences contrast
\begin{equation}
 D_i^\ell=
 \left(\hidden^\ell_{t_i}-\hidden^\ell_{t_i^-}\right)_{y_i=1}
 -\left(\hidden^\ell_{t_i}-\hidden^\ell_{t_i^-}\right)_{y_i=0}
\end{equation}
using the same candidate text and position while validity is changed by the task predicate or a matched record edit. We also compare length-, syntax-, depth-, and token-matched filler boundaries. If no local increment persists but the answer-query state remains count-coded and causally transportable, the result favors parallel terminal aggregation over a source-side running counter.

\section{Experimental Design}

\subsection{Realistic NIAH counting}

The current V2 audit contains 53 model--mode cells and 500 requests per cell (26,500 total). Each complete cell crosses ten target counts, five context lengths, and ten seeds. A valid target is a city--score audit record embedded among realistic distractors. The evaluation records four separate outcomes:
\begin{enumerate}
  \item numerical exactness of the parsed total;
  \item parse success;
  \item compliance with the strict final-answer format;
  \item truncation before a valid answer.
\end{enumerate}
Registered success requires all four gates. Enumeration precision/recall and trace style are diagnostics, not part of the numerical target.

The existing dataset is adequate for behavioral description but not yet a clean causal comparison of reasoning modes. Direct/index/bullet decoding is usually deterministic, whereas native thinking currently uses model-specific temperatures and larger token budgets. Some families compare different post-trained checkpoints rather than one checkpoint with a mode toggle. Therefore, all mechanistic claims will use the same weights, identical input, matched decoding where possible, and a separately reported compute/token-budget intervention.

Record exact checkpoint revision, tokenizer revision, attention implementation, dtype, and every stopping rule.
\end{todobox}

\subsection{Behavioral estimands and inference}

For each request, signed count error is $e=\pred-\gold$. We report exact accuracy, conditional bias, mean absolute and squared error, under/over-count probability, parse/format/truncation rates, and conditional error variance. Primary comparisons are paired within the same generated context and seed. The primary uncertainty procedure is a paired cluster bootstrap that resamples context-generation seeds within model and registered $(N,L)$ cells; McNemar tests provide paired binary checks. A discrete, heteroscedastic hierarchical error model with prespecified mode, $N$, $L$, and interaction terms is secondary because the model-family count is small. The multiplicity family covers primary modes, layers, and intervention doses declared before analysis. Model-generated trace style is post-treatment and is reported descriptively rather than interpreted causally.

\subsection{Mechanistic sample construction}

Mechanistic examples are stratified by $(N,L)$, output correctness, target placement, and trace correctness. We use three trace regimes:
\begin{enumerate}
  \item \textbf{canonical teacher forcing}, with machine-parseable item boundaries and a gold source alignment;
  \item \textbf{free-running native traces}, preserving ecological validity and error propagation;
  \item \textbf{counterfactual traces}, independently varying source count, trace extent, explicit index identity, and final answer position.
\end{enumerate}
Every free-running item is aligned to a source span or labeled hallucinated/unresolved; duplicates, inline prose, and unparsable traces remain explicit categories. We report identifiable-trace coverage and distinguish conditional aligned-trace estimands from all-rollout behavior. For progress, $k_{\rm emit}$, $k_{\rm valid}$, $k_{\rm unique}$, and remaining count are retained separately.

Main mode comparisons include all paired examples on a common prompt distribution and report four outcome strata: both correct, Direct-only correct, trace-mode-only correct, and both wrong. Common-correct comparisons are selection-conditioned sensitivities. A prespecified subset of overlapping-difficulty $(N,L)$ cells supplies an iso-difficulty comparison; post-hoc accuracy matching is not used as the primary estimate.

\section{Mechanism Analysis in Language Models}
\label{sec:mechanism}

\subsection{Representation-first analysis}

For every layer, we first measure candidate validity tags, source ordinals, prompt prefix counts, answer-query totals, trace pointers, semantic progress variables, and final totals. Ridge and low-rank nonlinear probes are cross-fitted with grouped splits that jointly hold out context templates, target identities, counts, lengths, and depth bins. A position-only model, token-window model, and shuffled-label probe establish controls~\citep{hewitt2019control}. We report decoder bias/error, calibration, conditional covariance, gap-normalized local SNR, shrinkage Mahalanobis discriminability, and generalization to unseen counts.

The decisive non-thinking comparison is among three sites:
\begin{enumerate}
  \item matched candidate endpoints, where a validity tag, source ordinal, or event update may appear;
  \item filler positions between candidates, where a carried prefix counter would have to persist;
  \item the answer query across layers, where a parallel aggregator may form a global total.
\end{enumerate}
An earlier 4k analysis found strong target-rank and final-total codes but filler prefix probes near permutation controls. Because natural target rank equals prefix count at target endpoints, the first result is not evidence for a running counter. The report also found high final-state seed-CV performance ($R^2=.95$, MAE .95), a compressed count manifold, and monotonic steering into piecewise-constant numeric answer regions. These findings motivate, but do not replace, candidate-validity counterfactuals in the paired V2 replication.

For trace generation, the preferred progress anchors are immediately before the next index and at the end of an enumerated item. Post-index states are secondary because the visible numeral leaks $k_{\rm emit}$. We use index-free bullets, randomly permuted symbolic indices, and a decoder that residualizes the current token embedding. Source pointer, emitted step, valid-item count, unique-valid count, remaining count, and final total are decoded separately; fixed-step counterfactuals vary item validity and duplication.

\begin{todobox}

\subsection{Attention-head taxonomy}

We rank candidate heads and paths on a discovery split using \cref{eq:broad,eq:targeted} and trace-readout/successor analogues. We then assess bundle-level union coverage, value/output contribution, and add/delete-source counterfactual sensitivity. The final taxonomy requires three properties:
\begin{enumerate}
  \item \textbf{selectivity}: the proposed routing signature exceeds matched controls;
  \item \textbf{replication}: the signature generalizes across seeds, counts, lengths, and at least two model families;
  \item \textbf{causal specificity}: query-local patching or ablation changes the predicted intermediate state and behavior while matched heads do not.
\end{enumerate}
Candidate roles are: target taggers, source-ordinal routers, broad retrieval paths, targeted pointer heads, successor/termination heads, trace-to-answer readout heads, aggregation writers, and numeric output components. ``Successor'' is reserved for a local transition such as $k\mapsto k+1$ or continue-versus-close~\citep{gould2023successor}; it does not name the full targeted-retrieval-and-aggregation algorithm.

Attention weights are discovery statistics, not explanations~\citep{jain2019attention}. In synthetic v10, descriptive mass and single-head necessity were sometimes weakly or negatively related. Accordingly, rankings are frozen before causal evaluation and all interventions include same-layer, matched-norm random controls.

\subsection{Causal evidence ladder}

We use increasingly specific interventions inspired by activation patching and circuit discovery~\citep{meng2022rome,wang2022ioi,conmy2023acdc}.

\paragraph{State steering.}
Estimate adjacent count-state displacements on a training split and add them at a held-out receiver. Because synthetic states follow curved manifolds, compare a global chord with a piecewise adjacent-centroid path. A valid local direction should move expected count monotonically with low off-target KL; a probe direction with no behavioral effect is diagnostic only~\citep{turner2023actadd,yuan2026hidden}.

\paragraph{Residual transplant.}
Patch a same-position donor state with count $c+\delta$ into a receiver with count $c$. Measure the expected count shift and donor-following probability. For trace-generating modes, independently transplant pointer, progress/termination, and final-total states. Patching a final-marker progress state should alter continuation/closure if it is a progress register; it need not transport the final scalar total.

\paragraph{Head-output patching.}
Construct clean/corrupt pairs that preserve count, query position, length, and lexical statistics while changing which source target is correct. Patch pre-output-projection per-query-head slices (important for grouped-query attention) and compute normalized recovery
\begin{equation}
 \operatorname{Rec}=\frac{m_{\rm patch}-m_{\rm corrupt}}
 {m_{\rm clean}-m_{\rm corrupt}}.
\end{equation}
Here $m$ is preregistered by task: correct-versus-corrupt source-identity margin, continue-versus-close logit difference, full numeric-string teacher-forced log probability, or constrained-rollout expected parsed count. Because numeric answers may span multiple tokens, final-count claims never rely only on one next-token logit. We report the raw patch effect and clean--corrupt denominator; normalized recovery is computed only above a frozen minimum-gap gate. For nested count donors, regress the expected-count shift on donor--receiver offset. A multi-head bundle with dose-dependent recovery is stronger evidence than a single high-attention head.

\paragraph{Query-local ablation.}
Mask a head only at the semantic query where its role is predicted: direct answer query for broad routing, trace retrieval query for pointer heads, item-end for successor/termination, and final answer query for trace readout. Global head ablation is reported only as a sensitivity analysis because it mixes all query positions.

\paragraph{Block and MLP writers.}
Patch and ablate whole block outputs, attention outputs, and MLP outputs before localizing a path. Test attention$\rightarrow$MLP$\rightarrow$total-state transport, direct-logit attribution along the local count tangent, and matched random low-rank subspaces. This prevents a head-only search from missing distributed aggregation writers.

\paragraph{Mediation.}
The final circuit claim requires a chain: candidate head intervention changes a preregistered semantic state; patching that state changes the next decision or total; conditioning/restoring the state attenuates the head effect. Effect-size correlation alone is not mediation.

\section{Synthetic Bridge and Training Dynamics}
\label{sec:synthetic}

Synthetic models permit exact source alignment, dense checkpoints, and interventions that are prohibitively expensive in LLMs. Their role is to develop and falsify measurements, not to prove that an LLM uses the same circuit.

\subsection{What one-seed v10 supports in its own setting}

Synthetic v10 trains separate 4-layer, 4-head, $d_{\rm model}=256$ causal transformers on counts 1--30 with learned absolute positions. Within this toy setting it provides five transferable lessons:
\begin{enumerate}
  \item total count is highly linearly readable at the final query in both modes, but adjacent-count geometry bends and becomes higher-dimensional with depth;
  \item direct answer queries use early broad-routing heads, while trace queries use targeted multi-head bundles;
  \item progress/termination and final-total states are causally separable;
  \item local count transport follows a curved centroid path better than one global $+1$ direction;
  \item readout attention mass alone does not imply that selected head slices carry the full scalar state.
\end{enumerate}

For example, direct broad-head query-local ablation can collapse accuracy, whereas targeted trace-model heads require a bundle to recover source identity. At the final residual, donor count is transported almost perfectly; a final trace-marker state instead controls early close without transporting the final scalar. These results satisfy parts of the causal evidence ladder in a toy model, but v10 uses one seed, symbolic markers, fixed short contexts, separately trained models, and teacher forcing for many analyses.

\subsection{v15 and v20 as candidate final settings}

Version 15 uses Tiny Shakespeare backgrounds, $d_{\rm model}=256$, RoPE or learned relative bias, all-sequence loss, and inserted marker targets. It changes several factors simultaneously and therefore serves as a negative design result rather than a clean ablation. Final counts approach ceiling even when trace fidelity collapses: RoPE trace exactness across low/mid/high count bands is approximately 68/49/17\%, and relative-bias trace exactness is 24/0/0\%, while final counts remain essentially perfect. Position-only controls at key trace/final sites can also reach ceiling. Thus correct answers do not establish faithful trace aggregation, and high trace-site probes can be positional.

Version 20 counts the union occurrences of a queried set of three natural characters in a 256-character Tiny Shakespeare window, restricted to totals 1--30. It uses a query-first format, RoPE, atomic count tokens, paired data/order for separately trained direct and trace models, and a two-stage objective: all-sequence loss through step 1500, then task-output loss through step 10,000. Both models have four layers, four heads, and $d_{\rm model}=256$. At the final checkpoint (one seed, 50 held-out free-running examples per count), the trace model reaches .912 exact count (Wilson 95\% CI [.897,.925]), .888 whole-trace exactness, and .983 ordered-marker accuracy. The direct model reaches .335 exact count (CI [.311,.359]), with MAE 1.177. Its output error does not support the simplest monotonic-noise claim: $r(C,|e|)=.021$ and $r(C,e^2)=.051$ in this test set. Hidden-state dispersion remains a separate TODO.

The original v20 run manifest records the causal stage as failed; later local repair artifacts require a complete provenance audit. Those artifacts nevertheless provide concrete hypotheses: a marker-successor component has a large query-local effect, top-2 retrieval-head patching shows .981 recovery versus .018 for random heads, and value-only transport (.952) dominates pattern-only transport (.076). These one-seed findings motivate a multi-seed rerun but do not make v20 a capability-matched final mechanism comparison.

\subsection{Training-dynamics estimands}

For checkpoints every 100--500 updates, we track free-running exact accuracy, teacher-forced local accuracy, source-routing selectivity, progress and total-state discriminability, local ablation damage, and patch recovery. Training step is supplemented by semantic exposure: the number of supervised occurrences of each retrieval step $k$, target identity, and answer token. In the current one seed, successor behavior appears first, teacher-forced final readout follows, and targeted retrieval specializes gradually around steps 3,300--6,000; free-running trace accuracy rises later. This ordering is descriptive because checkpoints are autocorrelated and the objective changes at step 1,500.

We distinguish three possibilities:
\begin{enumerate}
  \item \textbf{smooth formation}: a continuous mechanism metric explains behavior without a discrete change point;
  \item \textbf{phase transition}: a preregistered change-point model improves held-out likelihood/BIC and synchronizes across seeds and related mechanism metrics;
  \item \textbf{objective artifact}: the transition disappears, moves, or reverses when the loss switch and semantic exposure are controlled.
\end{enumerate}
This follows the broader use of mechanistic progress measures to explain apparently sudden learning~\citep{nanda2023grokking,olsson2022induction}.

Final synthetic suite: at least five seeds aligned by functional role rather than head index; matched task-token exposure; objective-switch 0/1500/3000/10000, natural/uniform-count, and length 128/256/384 controls; a direct run trained to comparable free-running accuracy; prespecified iso-accuracy checkpoints; generated-prefix states and interventions; pattern/value/residual patch curves; digit-wise and $C>30$ controls; and a complete provenance-tracked rerun of the v20 causal stage. Report transition-center/width intervals and do not call a one-seed change point a phase transition.
\end{todobox}

\section{Alternative Explanations and Required Controls}

\paragraph{Retrieval failure versus aggregation failure.}
High list recall with low bare-count accuracy, length dilution at fixed $N$, and direct-state steering are compatible with an aggregation/readout bottleneck. Nevertheless, source retrieval must be measured with the same prompt and decoding as counting. Target mass can fall merely because attention is normalized over longer contexts, and a multi-hop summary path can lack direct answer-to-source attention.

\paragraph{Visible-index leakage.}
Emitted-step progress can be decoded trivially from an index token or trace position. The main analysis uses pre-index/item-end anchors, symbolic index permutations, index-free traces, and fixed-step validity/duplication counterfactuals to separate $k_{\rm emit}$ from semantic $k_{\rm unique}$.

\paragraph{Position and trace length.}
Answer position often grows with trace extent. We cross trace extent with answer position: add padding to change position at fixed extent, and compensate with padding to fix answer position while extent changes. Patch tables retain donor/receiver positions, relative distance, and rotary phase.

\paragraph{Conditioning on correct traces.}
Correct-only traces select easier examples and can manufacture a clean manifold. Main estimates use all runs and stratify by trace correctness; canonical teacher forcing is labeled as a local competence test.

\paragraph{Capability mismatch.}
Direct and trace-generating modes currently have different accuracy, so a circuit difference may reflect success versus failure rather than computation style. Primary estimates use all paired prompts and the four paired correctness strata; preregistered overlapping-difficulty cells provide a secondary comparison. Common-correct and post-hoc iso-accuracy subsets are not treated as unbiased mode effects.

\paragraph{Different compute and decoding.}
Trace-generating modes use more generated tokens and sometimes a different temperature. We report a native-policy effect, a matched-decoding effect, and an explicit token-budget curve. Different post-trained checkpoints are not treated as a reasoning-mode toggle.

\paragraph{Attention superposition and redundancy.}
One semantic role may be distributed across heads, one head may be polysemantic, and a set of narrow heads may collectively provide broad coverage. Bundle/path-level add-delete tests, dose-response patching, and query-local ablation are preferred to naming the single highest-scoring head.

\paragraph{Off-manifold interventions.}
Large centroid replacements can create unnatural activations. We report activation norm, nearest-neighbor distance to natural states, downstream KL, and compare residual-preserving deltas with full replacement.

\section{Related Work}

CoT prompting improves performance on multi-step tasks~\citep{wei2022cot}, but trace faithfulness is not guaranteed~\citep{turpin2023unfaithful}. Recent work analyzes information flow and local causal structure inside reasoning traces~\citep{yang2026howcot,wei2026attricot}; the present task adds exact source alignments and a known algorithmic target. Work on hidden error signals further cautions that a strong probe can be diagnostic but not causal~\citep{yuan2026hidden}.

RULER extends single-needle retrieval to multi-needle and aggregation tasks~\citep{hsieh2024ruler}. Theoretical and empirical work shows that transformer counting can be limited by representation interference, vocabulary, and context length~\citep{yehudai2024count}. Our focus is complementary: we compare routing and state-update mechanisms across response modes in pretrained language models and controlled synthetic transformers.

Mechanistic interpretability provides the intervention tools used here: causal tracing and activation patching~\citep{meng2022rome}, circuit discovery~\citep{conmy2023acdc}, query-specific circuit analysis~\citep{wang2022ioi}, and activation steering~\citep{turner2023actadd}. Successor heads implement local increments over ordered token domains~\citep{gould2023successor}; we distinguish such a primitive from the broader retrieval--aggregation algorithm required by long-context counting.

\section{Limitations}

The realistic mechanistic evidence currently comes from heterogeneous report generations, prompts, decoding policies, and sample sizes. The strongest direct-mode evidence is not yet replicated in the V2 setting, and the strongest trace-mechanism evidence is synthetic. Open-weight Qwen/Gemma results may not generalize to proprietary or non-autoregressive systems. Linear probes can miss nonlinear or distributed codes, while powerful nonlinear probes can memorize nuisances. Patching can be off-manifold and ablation can trigger compensation. Synthetic models differ from LLMs in scale, pretraining, tokenization, and task familiarity. Finally, the law analysis is exploratory: candidate structures were selected after observing the data and must be validated on new model sizes or new condition cells.

The final artifact will include request-level data or hashes, exact prompts, model/tokenizer revisions, chat templates, generation parameters, semantic-anchor parsers, intervention code, grouped train/test splits, and seed-level tables. \section{Conclusion}

The current evidence supports a disciplined research program rather than a completed universal story. Direct language-model counting appears compatible with broad retrieval followed by compressed approximate aggregation, whereas trace generation may turn counting into targeted retrieval plus serial progress control and a separate final readout. The crucial distinction is between a decodable count code and a causal, generalizing counter. The proposed experiments make that distinction testable: they localize semantic anchors, control lexical and positional shortcuts, and require state and circuit interventions before assigning a mechanism name. If the LLM results reproduce the synthetic dissociation, counting will provide a compact case study of how visible reasoning changes internal routing and state organization; if they do not, the falsifiers will identify whether the failure lies in retrieval, aggregation, position, or the assumed counter abstraction.

\section{Statistical Specification for the Noise Hypothesis}

For mode $m$, site $s$, layer $\ell$, and count $c$, fit a grouped cross-validated decoder on training groups only. On held-out groups define
\begin{equation}
 b_{ms\ell}(c)=\E[\widehat C-C\mid c],\quad
 v_{ms\ell}(c)=\Var(\widehat C-C\mid c),\quad
 q_{ms\ell}(c)=v_{ms\ell}(c)+b_{ms\ell}(c)^2.
\end{equation}
On a dense $C=1{:}30$ mechanistic subset, estimate separate slopes for $\log(v+\epsilon)$ and $\log(q+\epsilon)$ against $\log c$ while controlling for context length, target-depth distribution, trace length, answer position, and prespecified difficulty cell. Representation-level analysis uses the pairwise, count-gap-normalized metrics in \cref{eq:noise}; sparse-grid analyses regress them on interval midpoint rather than pretending $c+1$ was observed. The primary contrast is Direct-final-total versus Native-final-total, with Direct versus Index reported separately. Prefix/progress comparisons are secondary because they label different computational objects. Cluster bootstrap intervals resample documents and seeds; Brown--Forsythe and shrinkage-Mahalanobis analyses are sensitivities. The claim requires convergent conditional-dispersion, MSE, and representation-discriminability evidence, not one significant slope.
