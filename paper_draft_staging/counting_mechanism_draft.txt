Counting in Context:
Broad Retrieval versus Targeted Retrieval and Aggregation
Authors to be added
Working paper for an ICLR 2027 submission

Draft of July 29, 2026

Abstract
Counting repeated records in a long context is a minimal task that nevertheless requires
retrieval, aggregation, and a stable discrete readout. We study language models under directanswer and trace-generating conditions; causal mode comparisons are restricted to identical
weights. A behavioral audit currently covers 26,500 realistic needle-in-a-haystack requests across
context length, target count, prompting mode, and model family. Explicit enumeration and
native reasoning often improve counting, but strict-format accuracy can substantially understate
numerical accuracy. We therefore formulate a mechanistic account that is deliberately stronger
than probe accuracy: direct answering is hypothesized to use distributed target tagging, broad
parallel retrieval, and a compressed global count readout, whereas trace generation is hypothesized
to use targeted retrieval together with separable progress/termination and final-total states. We
define the states, identifiability controls, conditional dispersion measures, and causal interventions
needed to distinguish these accounts, and use trained-from-scratch synthetic transformers as a
controlled bridge. Preliminary synthetic results support distinct routing strategies and causally
executable count states in a one-seed toy setting; realistic-LLM causal validation remains
incomplete. [TODO: Replace this final sentence with preregistered Qwen/Gemma
causal results and confidence intervals.]

Introduction

Long-context benchmarks often ask whether a model can retrieve one item from a large distractor
context. Counting extends retrieval in a small but consequential way: the model must identify all
matching records, avoid duplicates, aggregate them, and map an internal magnitude to an exact
integer. This is close to the multi-needle aggregation regime emphasized by RULER [5], and it
exposes failure modes that a single-needle test cannot.
Chain-of-thought (CoT) can improve reasoning accuracy [14], but an emitted trace is not automatically a faithful description of the internal computation [11]. The central question of this paper is
therefore mechanistic rather than purely behavioral:
Does direct answering count by a parallel, approximate aggregation over many retrieved
records, while thinking converts the same problem into targeted retrieval and serial
aggregation?

1

Earlier exploratory evidence is compatible with a more precise version of this contrast. In direct
mode, target recall can remain high when the total is wrong, suggesting—but not establishing—an
aggregation/readout bottleneck. In trace-generating mode, the model may externalize intermediate
items, but the state that controls trace progress need not be the state that controls the final total.
Consequently, we distinguish a count code from an algorithmic counter, and we separate target
validity, source identity, progress, termination, final aggregation, and output conversion.
This working paper makes four contributions, with their present status stated explicitly:
1. We give falsifiable definitions of target-validity tags, source ordinals and pointers, prefix counters,
aggregation states, semantic progress, broad retrieval, targeted retrieval, successor control, and
conditional representation dispersion.
2. We consolidate a realistic benchmark over N ∈ {1, 2, 3, 4, 5, 6, 8, 10, 20, 30} needles and L ∈
{2, 3, 5, 10, 20}k tokens, separating numerical accuracy from parsing, formatting, and truncation.
3. We specify a causal evidence ladder—steering, residual and head-output patching, query-local
ablation, and mediation—for Qwen3 and Gemma4 models that expose thinking and non-thinking
modes [2, 15].
4. We use synthetic transformers to study when routing roles and count-state geometry emerge
during training. Existing results motivate the LLM experiments but do not substitute for them.

2.2

Count code versus counter

Definition 1 (Count code). A site (a, ℓ) carries a count code for label c if a decoder fitted on
training documents predicts c above lexical, position-only, and shuffled-label controls on held-out
document templates, counts, lengths, target identities, and depths. A count code is a property of a
representation; it need not be used by the model.
Definition 2 (Target-validity tag). A candidate-end state carries a target-validity tag if it predicts
yi under identity, template, token, and position holdouts, and a local intervention changes whether
Ri contributes to a downstream aggregate while matched candidate states do not. Testing only gold
target endpoints cannot establish a validity tag.
Definition 3 (Source ordinal and pointer). The source ordinal of candidate Ri is its candidate
index i (or registered depth), independent of yi . A pointer state identifies which source span Ri
P
is being routed at a trace step. This differs from the target rank ri = j≤i yj : at a valid target
endpoint, ri = C≤ti by construction.
Definition 4 (Carried prefix counter). A sequence of prompt-local states carries a prefix counter
if states after target and matched non-target boundaries encode C≤t , the state persists through
intervening filler, target events induce an approximately unit update while matched distractors do
not, and patching that state changes the final count in the predicted direction.
Definition 5 (Aggregation state). A state is an aggregation state if adding, deleting, duplicating,
or flipping the validity of one source record changes it in the registered direction and restoring the
state mediates that record’s effect on the final total. A direct terminal aggregate is formed at a late
summary/answer site; a serial trace aggregate is updated across aligned trace items. Decoding the
total without these set-level counterfactuals is insufficient.

3

Definition 6 (Trace progress register). For a free-running trace, let kemit be the emitted-item count,
kvalid the number of source-aligned valid items, kunique the number of unique valid sources covered,
and N − kunique the remaining total. A progress register is a pre-index or item-end state that encodes
a preregistered semantic label—primary: kunique —and causally controls retrieval of another item or
termination after emitted step, item validity, and duplication are varied independently. Decoding
kemit from a visible index or its position is insufficient.
Definition 7 (Algorithmic counter). A family of states is an algorithmic counter only if it is
readable, causally transportable, and follows a stable update law sk+1 ≈ F (sk , ek ) that generalizes to
held-out counts, positions, and event identities. A linearly decodable scalar at the answer query is
insufficient.
This distinction resolves where to search for a non-thinking counter. The primary site for a totalcount code is the answer query, compared across matched prompts with different totals. Prompt-local
candidate and filler sites address a separate question: whether the model maintains a carried prefix
counter during the same forward pass. Natural target endpoints alone cannot identify that question
because target rank and prefix count are identical there. The primary design therefore fixes candidate
ordinal while flipping validity, fixes the number of seen candidates while varying the valid prefix,
and tests persistence at matched filler boundaries. A sweep over separately truncated prompts is
useful corroboration, but it cannot alone prove a persistent within-sequence state.

Mechanistic Hypotheses

Hypothesis 1 (Direct broad aggregation). Direct mode identifies target records in distributed
prompt representations, routes many of them through a broad head/path bundle, forms a compressed
global magnitude in later layers, and maps that magnitude through a quantized numeric-token readout.
It need not maintain a persistent prefix counter at source positions.
Hypothesis 2 (Trace-targeted retrieval and serial control). A trace-generating condition repeatedly
targets a particular source record, updates a progress/termination register, and later constructs a
distinct final-total state. The visible trace supplies extra serial computation and an external memory,
but the last written index is not necessarily the final count source.
Hypothesis 3 (Heteroscedasticity). As C grows, direct-mode per-count spacing contracts and/or
conditional dispersion grows, causing local SNR to decrease faster than in trace-generating modes.
The primary comparison is final-total versus final-total on a preregistered dense count set and
prespecified overlapping-difficulty cells; correctness-conditioned and post-hoc iso-accuracy analyses
are sensitivity checks. Trace progress k is never compared directly with a direct total C.

Experimental Design

4.1

Realistic NIAH counting

The current V2 audit contains 53 model–mode cells and 500 requests per cell (26,500 total). Each
complete cell crosses ten target counts, five context lengths, and ten seeds. A valid target is a
city–score audit record embedded among realistic distractors. The evaluation records four separate
outcomes:
1. numerical exactness of the parsed total;
2. parse success;
6

3. compliance with the strict final-answer format;
4. truncation before a valid answer.
Registered success requires all four gates. Enumeration precision/recall and trace style are diagnostics,
not part of the numerical target.
The existing dataset is adequate for behavioral description but not yet a clean causal comparison of
reasoning modes. Direct/index/bullet decoding is usually deterministic, whereas native thinking
currently uses model-specific temperatures and larger token budgets. Some families compare different
post-trained checkpoints rather than one checkpoint with a mode toggle. Therefore, all mechanistic
claims will use the same weights, identical input, matched decoding where possible, and a separately
reported compute/token-budget intervention.

4.3

Behavioral estimands and inference

For each request, signed count error is e = Cb − C. We report exact accuracy, conditional bias,
mean absolute and squared error, under/over-count probability, parse/format/truncation rates, and
conditional error variance. Primary comparisons are paired within the same generated context
and seed. The primary uncertainty procedure is a paired cluster bootstrap that resamples contextgeneration seeds within model and registered (N, L) cells; McNemar tests provide paired binary
checks. A discrete, heteroscedastic hierarchical error model with prespecified mode, N , L, and
interaction terms is secondary because the model-family count is small. The multiplicity family
covers primary modes, layers, and intervention doses declared before analysis. Model-generated
trace style is post-treatment and is reported descriptively rather than interpreted causally.

4.4

Mechanistic sample construction

Mechanistic examples are stratified by (N, L), output correctness, target placement, and trace
correctness. We use three trace regimes:
1. canonical teacher forcing, with machine-parseable item boundaries and a gold source alignment;
2. free-running native traces, preserving ecological validity and error propagation;
3. counterfactual traces, independently varying source count, trace extent, explicit index identity,
and final answer position.
Every free-running item is aligned to a source span or labeled hallucinated/unresolved; duplicates,
inline prose, and unparsable traces remain explicit categories. We report identifiable-trace coverage
and distinguish conditional aligned-trace estimands from all-rollout behavior. For progress, kemit ,
kvalid , kunique , and remaining count are retained separately.
Main mode comparisons include all paired examples on a common prompt distribution and report
four outcome strata: both correct, Direct-only correct, trace-mode-only correct, and both wrong.
Common-correct comparisons are selection-conditioned sensitivities. A prespecified subset of
overlapping-difficulty (N, L) cells supplies an iso-difficulty comparison; post-hoc accuracy matching
is not used as the primary estimate.

Mechanism Analysis in Language Models

6.1

Representation-first analysis

For every layer, we first measure candidate validity tags, source ordinals, prompt prefix counts,
answer-query totals, trace pointers, semantic progress variables, and final totals. Ridge and low-rank
nonlinear probes are cross-fitted with grouped splits that jointly hold out context templates, target
identities, counts, lengths, and depth bins. A position-only model, token-window model, and
shuffled-label probe establish controls [4]. We report decoder bias/error, calibration, conditional
covariance, gap-normalized local SNR, shrinkage Mahalanobis discriminability, and generalization
to unseen counts.
The decisive non-thinking comparison is among three sites:
1. matched candidate endpoints, where a validity tag, source ordinal, or event update may appear;
2. filler positions between candidates, where a carried prefix counter would have to persist;
3. the answer query across layers, where a parallel aggregator may form a global total.
An earlier 4k analysis found strong target-rank and final-total codes but filler prefix probes near
permutation controls. Because natural target rank equals prefix count at target endpoints, the
10

first result is not evidence for a running counter. The report also found high final-state seedCV performance (R2 = .95, MAE .95), a compressed count manifold, and monotonic steering
into piecewise-constant numeric answer regions. These findings motivate, but do not replace,
candidate-validity counterfactuals in the paired V2 replication.
For trace generation, the preferred progress anchors are immediately before the next index and at the
end of an enumerated item. Post-index states are secondary because the visible numeral leaks kemit .
We use index-free bullets, randomly permuted symbolic indices, and a decoder that residualizes
the current token embedding. Source pointer, emitted step, valid-item count, unique-valid count,
remaining count, and final total are decoded separately; fixed-step counterfactuals vary item validity
and duplication.

6.2

Attention-head taxonomy

We rank candidate heads and paths on a discovery split using equations (3) and (4) and tracereadout/successor analogues. We then assess bundle-level union coverage, value/output contribution,
and add/delete-source counterfactual sensitivity. The final taxonomy requires three properties:
1. selectivity: the proposed routing signature exceeds matched controls;
2. replication: the signature generalizes across seeds, counts, lengths, and at least two model
families;
3. causal specificity: query-local patching or ablation changes the predicted intermediate state
and behavior while matched heads do not.
Candidate roles are: target taggers, source-ordinal routers, broad retrieval paths, targeted pointer
heads, successor/termination heads, trace-to-answer readout heads, aggregation writers, and numeric
output components. “Successor” is reserved for a local transition such as k 7→ k + 1 or continueversus-close [3]; it does not name the full targeted-retrieval-and-aggregation algorithm.
Attention weights are discovery statistics, not explanations [6]. In synthetic v10, descriptive mass
and single-head necessity were sometimes weakly or negatively related. Accordingly, rankings are
frozen before causal evaluation and all interventions include same-layer, matched-norm random
controls.

Causal evidence ladder

We use increasingly specific interventions inspired by activation patching and circuit discovery [1, 7,

a held-out receiver. Because synthetic states follow curved manifolds, compare a global chord with a
piecewise adjacent-centroid path. A valid local direction should move expected count monotonically
with low off-target KL; a probe direction with no behavioral effect is diagnostic only [10, 18].

Synthetic Bridge and Training Dynamics

Synthetic models permit exact source alignment, dense checkpoints, and interventions that are
prohibitively expensive in LLMs. Their role is to develop and falsify measurements, not to prove
that an LLM uses the same circuit.

7.1

What one-seed v10 supports in its own setting

Synthetic v10 trains separate 4-layer, 4-head, dmodel = 256 causal transformers on counts 1–30 with
learned absolute positions. Within this toy setting it provides five transferable lessons:
1. total count is highly linearly readable at the final query in both modes, but adjacent-count
geometry bends and becomes higher-dimensional with depth;
2. direct answer queries use early broad-routing heads, while trace queries use targeted multi-head
bundles;
13

3. progress/termination and final-total states are causally separable;
4. local count transport follows a curved centroid path better than one global +1 direction;
5. readout attention mass alone does not imply that selected head slices carry the full scalar state.
For example, direct broad-head query-local ablation can collapse accuracy, whereas targeted tracemodel heads require a bundle to recover source identity. At the final residual, donor count
is transported almost perfectly; a final trace-marker state instead controls early close without
transporting the final scalar. These results satisfy parts of the causal evidence ladder in a toy
model, but v10 uses one seed, symbolic markers, fixed short contexts, separately trained models,
and teacher forcing for many analyses.

Figure 2: Preliminary synthetic v10 attention signatures. Direct answer queries show broad target
coverage; trace queries show targeted source retrieval; final trace readout is a separate candidate
role. These are descriptive rankings and require local interventions for causal naming.

7.2

v15 and v20 as candidate final settings

Version 15 uses Tiny Shakespeare backgrounds, dmodel = 256, RoPE or learned relative bias, allsequence loss, and inserted marker targets. It changes several factors simultaneously and therefore
serves as a negative design result rather than a clean ablation. Final counts approach ceiling
even when trace fidelity collapses: RoPE trace exactness across low/mid/high count bands is
approximately 68/49/17%, and relative-bias trace exactness is 24/0/0%, while final counts remain
essentially perfect. Position-only controls at key trace/final sites can also reach ceiling. Thus correct
answers do not establish faithful trace aggregation, and high trace-site probes can be positional.
Version 20 counts the union occurrences of a queried set of three natural characters in a 256-character
Tiny Shakespeare window, restricted to totals 1–30. It uses a query-first format, RoPE, atomic count
tokens, paired data/order for separately trained direct and trace models, and a two-stage objective:
all-sequence loss through step 1500, then task-output loss through step 10,000. Both models have
four layers, four heads, and dmodel = 256. At the final checkpoint (one seed, 50 held-out free-running
examples per count), the trace model reaches .912 exact count (Wilson 95% CI [.897,.925]), .888
whole-trace exactness, and .983 ordered-marker accuracy. The direct model reaches .335 exact count
(CI [.311,.359]), with MAE 1.177. Its output error does not support the simplest monotonic-noise
claim: r(C, |e|) = .021 and r(C, e2 ) = .051 in this test set. Hidden-state dispersion remains a
separate TODO.
The original v20 run manifest records the causal stage as failed; later local repair artifacts require a
complete provenance audit. Those artifacts nevertheless provide concrete hypotheses: a marker14

successor component has a large query-local effect, top-2 retrieval-head patching shows .981 recovery
versus .018 for random heads, and value-only transport (.952) dominates pattern-only transport
(.076). These one-seed findings motivate a multi-seed rerun but do not make v20 a capability-matched
final mechanism comparison.

7.3

Training-dynamics estimands

For checkpoints every 100–500 updates, we track free-running exact accuracy, teacher-forced
local accuracy, source-routing selectivity, progress and total-state discriminability, local ablation
damage, and patch recovery. Training step is supplemented by semantic exposure: the number of
supervised occurrences of each retrieval step k, target identity, and answer token. In the current one
seed, successor behavior appears first, teacher-forced final readout follows, and targeted retrieval
specializes gradually around steps 3,300–6,000; free-running trace accuracy rises later. This ordering
is descriptive because checkpoints are autocorrelated and the objective changes at step 1,500.
We distinguish three possibilities:
1. smooth formation: a continuous mechanism metric explains behavior without a discrete change
point;
2. phase transition: a preregistered change-point model improves held-out likelihood/BIC and
15

synchronizes across seeds and related mechanism metrics;
3. objective artifact: the transition disappears, moves, or reverses when the loss switch and
semantic exposure are controlled.
This follows the broader use of mechanistic progress measures to explain apparently sudden
learning [8, 9].

Alternative Explanations and Required Controls

Retrieval failure versus aggregation failure. High list recall with low bare-count accuracy,
length dilution at fixed N , and direct-state steering are compatible with an aggregation/readout
bottleneck. Nevertheless, source retrieval must be measured with the same prompt and decoding as
counting. Target mass can fall merely because attention is normalized over longer contexts, and a
multi-hop summary path can lack direct answer-to-source attention.
Visible-index leakage. Emitted-step progress can be decoded trivially from an index token or
trace position. The main analysis uses pre-index/item-end anchors, symbolic index permutations,
index-free traces, and fixed-step validity/duplication counterfactuals to separate kemit from semantic
kunique .
Position and trace length. Answer position often grows with trace extent. We cross trace
extent with answer position: add padding to change position at fixed extent, and compensate with
padding to fix answer position while extent changes. Patch tables retain donor/receiver positions,
relative distance, and rotary phase.
Conditioning on correct traces. Correct-only traces select easier examples and can manufacture
a clean manifold. Main estimates use all runs and stratify by trace correctness; canonical teacher
forcing is labeled as a local competence test.
Capability mismatch. Direct and trace-generating modes currently have different accuracy, so a
circuit difference may reflect success versus failure rather than computation style. Primary estimates
use all paired prompts and the four paired correctness strata; preregistered overlapping-difficulty
cells provide a secondary comparison. Common-correct and post-hoc iso-accuracy subsets are not
treated as unbiased mode effects.
Different compute and decoding. Trace-generating modes use more generated tokens and
sometimes a different temperature. We report a native-policy effect, a matched-decoding effect, and
16

an explicit token-budget curve. Different post-trained checkpoints are not treated as a reasoningmode toggle.
Attention superposition and redundancy. One semantic role may be distributed across heads,
one head may be polysemantic, and a set of narrow heads may collectively provide broad coverage.
Bundle/path-level add-delete tests, dose-response patching, and query-local ablation are preferred
to naming the single highest-scoring head.
Off-manifold interventions. Large centroid replacements can create unnatural activations. We
report activation norm, nearest-neighbor distance to natural states, downstream KL, and compare
residual-preserving deltas with full replacement.

Related Work

CoT prompting improves performance on multi-step tasks [14], but trace faithfulness is not guaranteed [11]. Recent work analyzes information flow and local causal structure inside reasoning
traces [13, 16]; the present task adds exact source alignments and a known algorithmic target. Work
on hidden error signals further cautions that a strong probe can be diagnostic but not causal [18].
RULER extends single-needle retrieval to multi-needle and aggregation tasks [5]. Theoretical and
empirical work shows that transformer counting can be limited by representation interference,
vocabulary, and context length [17]. Our focus is complementary: we compare routing and stateupdate mechanisms across response modes in pretrained language models and controlled synthetic
transformers.
Mechanistic interpretability provides the intervention tools used here: causal tracing and activation
patching [7], circuit discovery [1], query-specific circuit analysis [12], and activation steering [10].
Successor heads implement local increments over ordered token domains [3]; we distinguish such a
primitive from the broader retrieval–aggregation algorithm required by long-context counting.

10

Limitations

The realistic mechanistic evidence currently comes from heterogeneous report generations, prompts,
decoding policies, and sample sizes. The strongest direct-mode evidence is not yet replicated in the
V2 setting, and the strongest trace-mechanism evidence is synthetic. Open-weight Qwen/Gemma
results may not generalize to proprietary or non-autoregressive systems. Linear probes can miss
nonlinear or distributed codes, while powerful nonlinear probes can memorize nuisances. Patching
can be off-manifold and ablation can trigger compensation. Synthetic models differ from LLMs
in scale, pretraining, tokenization, and task familiarity. Finally, the law analysis is exploratory:
candidate structures were selected after observing the data and must be validated on new model
sizes or new condition cells.

Conclusion

The current evidence supports a disciplined research program rather than a completed universal story.
Direct language-model counting appears compatible with broad retrieval followed by compressed
approximate aggregation, whereas trace generation may turn counting into targeted retrieval plus
serial progress control and a separate final readout. The crucial distinction is between a decodable
count code and a causal, generalizing counter. The proposed experiments make that distinction
testable: they localize semantic anchors, control lexical and positional shortcuts, and require state
and circuit interventions before assigning a mechanism name. If the LLM results reproduce the
synthetic dissociation, counting will provide a compact case study of how visible reasoning changes
internal routing and state organization; if they do not, the falsifiers will identify whether the failure
lies in retrieval, aggregation, position, or the assumed counter abstraction.

Statistical Specification for the Noise Hypothesis

For mode m, site s, layer ℓ, and count c, fit a grouped cross-validated decoder on training groups
only. On held-out groups define
bmsℓ (c) = E[Cb − C | c],

vmsℓ (c) = Var(Cb − C | c),

qmsℓ (c) = vmsℓ (c) + bmsℓ (c)2 .

(11)

On a dense C = 1:30 mechanistic subset, estimate separate slopes for log(v + ϵ) and log(q + ϵ)
against log c while controlling for context length, target-depth distribution, trace length, answer
position, and prespecified difficulty cell. Representation-level analysis uses the pairwise, countgap-normalized metrics in equation (8); sparse-grid analyses regress them on interval midpoint
rather than pretending c + 1 was observed. The primary contrast is Direct-final-total versus
Native-final-total, with Direct versus Index reported separately. Prefix/progress comparisons are
secondary because they label different computational objects. Cluster bootstrap intervals resample
documents and seeds; Brown–Forsythe and shrinkage-Mahalanobis analyses are sensitivities. The
claim requires convergent conditional-dispersion, MSE, and representation-discriminability evidence,
not one significant slope.
