\begin{abstract}
Counting sparse, semantically defined records in a long context requires every
valid occurrence to affect the answer exactly once. In a realistic
needle-in-a-haystack audit, native chain-of-thought (CoT), numbered
enumeration, and bullet enumeration are substantially more accurate than
direct non-thinking answers in the moderate-count regime. All interfaces
degrade as count and context length grow, but current coefficients are not
stable enough to support a universal empirical law.

We ask which computational change explains the CoT advantage. Rather than
assuming that Direct maintains a noisy running counter, we test two Direct
programs: record-wise running update and answer-time broad aggregation. We
contrast both with a sequential CoT program consisting of targeted
source retrieval, trace writing, semantic progress transition, next-source or
stop control, and terminal readout. The experiment registers exact
residual-stream token landmarks, operational attention-role scores, and
length-preserving sibling stimuli that separate local updates from final
totals. Representation claims require held-out decodability and the correct
\(+1/0\) dynamics; mechanism claims additionally require activation
interventions to propagate through source identity, unique coverage, progress,
terminal state, and the complete parsed answer. Qwen3-8B and Gemma4-E4B are
co-primary mechanism models. PCA and attention maps remain descriptive until
the corresponding causal links pass. Existing synthetic results establish
measurement feasibility; realistic LLM mechanism results remain registered

\section{Introduction}

Long-context retrieval benchmarks usually ask whether a model can recover one item from distractors. Counting is stricter: every valid record must contribute once, while invalid and repeated records must contribute zero. A correct answer therefore requires source discovery, duplicate-free coverage, aggregation, stopping, and numerical readout. Multi-needle tasks such as RULER expose failures that single-needle accuracy can conceal~\citep{hsieh2024ruler}.

CoT often improves multi-step reasoning~\citep{wei2022cot}, but the emitted trace need not faithfully report the computation that produced the answer~\citep{turpin2023unfaithful}. The question of this paper is therefore mechanistic:

\begin{quote}
\emph{How does CoT help a language model count, and which causal computation distinguishes it from a direct non-thinking answer?}
\end{quote}

We test a deliberately small contrast. Direct answering may update a
predicate-conditioned state after each record, or it may construct the
task-relevant total only near the answer through a broad multi-record
aggregation route. CoT may instead issue a sequence of source-specific
retrievals, write the retrieved items into an external trace, update semantic
progress, and use that state to retrieve the next source or stop. The central
candidate benefit is an algorithmic path change: a difficult high-fan-in
retrieval-and-aggregation operation is replaced by repeated low-fan-in
retrievals whose intermediate results remain available in the generated
prefix. We do not assume in advance that either interface contains a scalar
neural counter, that a visible index is faithful, or that more generated
tokens are sufficient.

The paper follows one evidence chain:
\begin{equation}
\begin{aligned}
\text{behavioral contrast}
&\longrightarrow
\text{registered computation}
\longrightarrow
\text{causal state}\\[-0.15em]
&\longrightarrow
\text{functional component}
\longrightarrow
\text{complete answer}.
\end{aligned}
\label{eq:evidence-chain}
\end{equation}
Each arrow has a separate falsification test. A probe or PCA curve can establish representation, not use. An attention heatmap can nominate a route, not establish its function. An ablation can show necessity, but the proposed explanation of CoT requires restoration of the intervening retrieval or count state and recovery of the complete parsed answer.

Our contributions are:
\begin{enumerate}
  \item We consolidate the behavioral phenomenon over needle count, context length, response mode, and a broad model panel, while treating any parametric ``law'' as a held-out prediction problem rather than a fitted slogan.
  \item We construct equal-length sibling families and prompt-policy controls
  that distinguish a Direct running update from terminal broad aggregation and
  remove visible-index leakage from CoT progress.
  \item We register exact record, retrieval, progress, and terminal token
  landmarks, and define broad-aggregation, targeted-retrieval, and
  progress-transition candidates whose functional names require held-out
  interventions.
  \item We register the decisive time-indexed chain: perturb routing, measure
  source identity and unique coverage, measure progress and terminal state,
  and restore a clean mediator while the upstream component remains perturbed.
\end{enumerate}

The realistic mechanism study is co-primary in Qwen3-8B and
Gemma4-E4B~\citep{yang2025qwen3,gemmateam2026gemma4}. Model identities,
semantic sites, endpoints, and intervention logic are shared, but heads are
aligned by function and relative depth rather than numerical index. Synthetic
transformers serve as a controlled bridge for measurement design and training
dynamics; they do not substitute for causal results in pretrained LLMs.

\section{Conclusion}

This paper is designed to answer ``How does CoT help language models count?''
with a causal comparison of computations rather than a catalog of probes and
attention maps. Direct answering is tested for a record-wise running update
and for terminal broad aggregation. CoT is tested for targeted retrieval,
trace writing, semantic progress transition, next-source or stop control, and
terminal readout. The strongest conclusion requires interventions to
propagate through source identity, unique coverage, progress and stopping,
terminal state, and the complete count.

The claim will be narrowed to the links the data actually support. A
decodable Direct record state without the sibling-controlled \(+1/0\) profile
and propagated patches is ordinal information, not a running counter. A CoT
state that fails label controls is numeric scaffolding, not semantic progress.
An attention component without a proximal source or stopping effect is a
signature, not a circuit. If equal-length null scratchpads reproduce the
benefit, prefer an extra-compute account; if common evidence removes the mode
gap, prefer retrieval mediation; if a residual gap remains, test state
construction and terminal readout. Qwen3-8B and Gemma4-E4B provide functional
replication only when the same semantic links hold, even if their layers and
head identities differ.
